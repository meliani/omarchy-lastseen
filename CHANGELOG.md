# Changelog

## 1.0.0 — 2026-11-20

First public release.

- Chat list with pictures, unread counts, delivery ticks, search, filters and new chats by number
- Conversations: text with links, quoted replies, reactions, edit, delete for everyone
- Photos, videos, stickers, documents, voice notes, locations, contacts and polls inline
- Voice notes recorded from the bar, loudness evened out
- Files from a picker or pasted images, with captions
- Deleted messages and their media kept, marked as deleted
- Contact and group profiles, local names, linking hidden numbers, unread / block / leave
- Online, typing and last seen (opt-in); appear offline by default
- Several accounts with a switcher; grouped notifications per chat
- Instant updates over RabbitMQ, polling without it
- Demo account with fictional chats
- Server kit: Evolution API 2.3.7, Postgres, Redis, RabbitMQ and optional Caddy HTTPS in one command
- English and French
